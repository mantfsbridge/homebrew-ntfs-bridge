# Homebrew tap for NTFS Bridge

```sh
brew tap mantfsbridge/homebrew-ntfs-bridge
brew install --cask ntfsbridge
```

Downloads come from the public release repository
[mantfsbridge/ntfs-bridge-releases](https://github.com/mantfsbridge/ntfs-bridge-releases);
updates are delivered in-app through the Sparkle feed at
<https://ntfsbridge.app/appcast.xml>.
